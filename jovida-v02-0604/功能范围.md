### Today tab
默认为 list 模式，就跟原来一样。
可以切换为 Focus 模式。Focus 模式类似盲盒 / 扭蛋机，用户可以随机抽取一个最适合用户现在干的任务。（主要服务那些任务多，启动困难，ADHD 等用户）

### 已经延期的Todo的 maybe later 功能
- 哪些位置会出现已经延期的Todo：Today 的列表模式下；All tab 的按照 Date 分组；Calendar 的 Today 和之前的日期中
- 这种情况下，不继续制造压力。过期任务不只是变红，而是可以给价值
    - 一键重排（具体功能我还没想好）
    - 一键扔进 Todo 坟墓
        - 要有一个任务坟墓详情页，比较有沉浸感的视觉，真的是一个坟墓页，里面是已经被扔进去的 Todos
    - 一键拆小（联动 Magic subtasks）
    - 和角色形象联动，比如展示角色疯了，或者 xx 的形象 / 表情（利用你 codex 的生图能力画出相关的形象并且展示在界面上）

### Today Reset
Today 界面有一个 一键智能躺平/摆烂/休假模式，点击后自动把不重要任务挪走（重要任务仍提醒）
- 挪走，挪到哪我还没想好，比如可能是都顺延一天，顺延 N 天？让用户选择

### Magic substasks - 沉浸模式（也称 tiny step 模式）
参考 Coach Plan 的沉浸全屏模式，让用户一次只聚焦于一个 Todo 中的一个子任务

### Todo 详情页
应该有几个操作按钮（展示我们的功能亮点，为了传播）
- Magic Subtasks
- 扔进任务坟墓
—— 这个是小亮点，但不应该喧宾夺主
